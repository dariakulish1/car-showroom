# car-showroom
React SPA for browsing vehicles, filtering models, viewing details, and adding comments with localStorage persistence.

## Live Demo

🔗 https://car-showroom-mv05rm41m-darias-projects-91f8a453.vercel.app/

## GitHub Repository

🔗 https://github.com/dariakulish1/car-showroom

## Features

- Display a list of vehicles fetched from the DummyJSON API.
- Search and filter vehicles.
- View detailed information about each vehicle.
- Display vehicle reviews.
- Add new comments with form validation.
- Persist user-added comments using Local Storage.
- Client-side routing with React Router.

## Technologies

- React
- React Router
- JavaScript
- SCSS
- npm
- DummyJSON API
- Local Storage

## Getting Started

### Clone the repository

```bash
git clone https://github.com/dariakulish1/car-showroom.git
```

### Navigate to the project folder

```bash
cd car-showroom-app
```

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm start
```

The application will be available at:

```
http://localhost:3000
```

## Build for production

```bash
npm run build
```

## API

The application uses the DummyJSON API:

https://dummyjson.com/products/category/vehicle
